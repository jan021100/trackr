# Frontend design
1. Inspect existing brand, components, user goals, real content and design conventions.
2. Plan hierarchy, primary task, responsive behavior, states and keyboard navigation before visual polishing.
3. Avoid unmotivated bento layouts, repeated feature cards, terminal mockups, decorative orbs, dot grids, vague copy or fake demos.
4. Fonts (Inter/Geist), Lucide icons, animations, gradients and other popular choices are NOT forbidden. Keep choices that work.
5. Check semantics, labels, contrast, focus, mobile usability, reduced motion, loading/empty/error states.
6. Verify against real or representative content at narrow/wide viewports. Use browser/Playwright tests only if configured.
7. Summarize design decisions, results and limitations. Do not install third-party skills by default.
